# 📊 Telecom Customer Churn Analytics & Prediction

An end-to-end Machine Learning project that predicts customer churn for a telecom company using classification algorithms and provides interactive business insights through a Streamlit dashboard.

## 📌 Project Overview

Customer churn is one of the biggest challenges faced by telecom companies. This project predicts whether a customer is likely to leave the company by analyzing customer demographics, subscription details, tenure, contract type, monthly charges, and customer lifetime value (CLTV).

The application combines:

- Machine Learning
- Data Analytics
- Interactive Dashboard
- Business Insights
- Customer Risk Prediction
